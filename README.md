## 💻 Local Setup & Execution

### Option A: Python Native Server (Port 8080 with Live SMTP)
```bash
# Clone the repository
git clone https://github.com/mruthramoorthi/portfolio.git
cd portfolio

# Configure environment variables
cp .env.example .env

# Run the local server
python3 server.py
```
Open [**http://localhost:8080/**](http://localhost:8080/) in your browser.

### Option B: Apache / XAMPP (`htdocs`)
```bash
sudo cp -r portfolio /opt/lampp/htdocs/
```
Open [**http://localhost/portfolio/**](http://localhost/portfolio/) in your browser.
